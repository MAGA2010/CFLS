# 数据字典（v1）

迁移事实源：`apps/api/migrations/001_initial.sql`。

| 表 | 关键字段 | 约束与用途 |
| --- | --- | --- |
| users | id, username, password_hash, status | UUID 主键；用户名大小写不敏感唯一；bcrypt cost 12；停用后会话失效 |
| user_roles | user_id, role | 主键(user_id, role)；角色仅 editor/reviewer/admissions/admin |
| sessions | id, user_id, token_hash, expires_at, revoked_at, created_at | 只存 token SHA-256；支持过期、撤销、空闲/绝对 TTL |
| contents | id, type, category, title, summary, body, status, version, author_id, reviewer_id, published_at, is_demo, timestamps | type/category 白名单配对；title/body/summary 长度约束；published 必须有 published_at；version 乐观锁 |
| content_revisions | id, content_id, version, snapshot, actor_id, created_at | 每次创建/更新/状态转换写不可重复版本快照 |
| audit_events | id, actor_id, action, target_type, target_id, request_id, result, created_at | 只追加；数据库 trigger 拒绝 UPDATE/DELETE；不存请求正文 |
| inquiries | id, kind, test_name, test_contact, message, status, is_test, created_at | 仅合成测试咨询；is_test 必须 true；字段长度受控 |
| idempotency_keys | scope, key, request_hash, result_ref, expires_at, created_at | 主键(scope, key)；同键同内容重放，同键异内容 409 |

## 内容状态

```text
draft --submit--> pending_review --approve--> approved --publish--> published
                         └--reject--> draft               published --unpublish--> draft
```

每次成功转换在同一事务中更新 `contents`、写 `content_revisions` 与 `audit_events`。

## 索引

- 公开内容：`(type, status, published_at DESC)`
- 作者视图：`(author_id, status)`
- 新闻稳定排序：`(status, published_at DESC, id DESC)`
- 修订：`(content_id, version DESC)`
- 审计：`created_at DESC`、`(target_type, target_id)`
- 咨询：`created_at DESC`
- 幂等过期清理：`expires_at`
