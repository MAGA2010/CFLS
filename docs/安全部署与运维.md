# 安全、部署、运维和上线门槛

本文件规定候选版最低工程控制和测试方法，不能代替独立安全评估、校方审核或上线批准。A 负责服务端/环境，B/C 分别负责客户端，负责人验收证据。

## 1. 认证与会话

1. 后台采用成熟的服务端认证和会话库；凭据只存服务端慢哈希（例如 Argon2id，或团队验证可用的等效方案），不记录明文密码或写入日志。初始测试账户通过仅 local/staging 的脚本生成，账号密码在私密渠道提供；生产环境不得创建默认账户。
2. 浏览器后台优先使用服务端随机会话和 `HttpOnly`、`Secure`（HTTPS 环境）、`SameSite` cookie；配置 CSRF 防护（token 或同等有效方案、校验 Origin）并明确会话生命周期、空闲/绝对过期与注销撤销。本机 HTTP 的安全 cookie 例外只限 local。若选择 bearer token，必须在设计记录中解释存放、刷新、撤销和 XSS 风险，不得把长期令牌存入 localStorage。
3. 登录失败统一提示，限制 IP 与账号维度的尝试并记录安全事件；限流部署是单实例还是共享存储须写明，多实例部署不能依赖孤立进程内计数。生产环境密码规则、二次验证、锁定/解锁和管理责任由校方确定并完成后才开放生产后台。
4. 服务端验证每次请求的角色、对象、归属及状态；禁止客户端自行传 user_id 代替服务端身份。受保护响应禁用缓存，避免泄露；未授权请求不能返回对象内容。

## 2. 输入、输出与网络

- DTO 白名单、长度上限、枚举和类型验证；分页上限、请求体体积上限；参数化查询/ORM 安全使用；HTML 安全输出；禁止 URL 拼接数据库语句；文件上传为 P1，未实现不暴露上传端点。
- 管理 API 配置精确 CORS 和可信代理、HTTPS、HSTS 的部署策略；限制来源、请求体大小、慢请求/超时；不把反向代理转发头作为无需验证的用户身份。
- 安全头依管理端实际部署配置，最低包括合理 CSP、防 MIME 嗅探、点击劫持防护；不影响微信平台合法请求。禁用详细错误/目录遍历；依赖漏洞按严重度分级并记录。
- 测试咨询只在明确开启的非生产环境可用，且 UI 明示使用合成数据；禁止假名代表真实用户或在公共仓库提交数据。上线前真实表单必须重新设计告知、同意、目的、权限、留存、删除及事件处置，校方审定后另行实现和测试。

## 3. 日志、审计、监控

结构化日志至少时间、级别、服务、requestId、路径模板、HTTP 状态及耗时；不记录 cookie、Authorization、密码、完整咨询内容、联系方式、数据库连接字符串或完整请求体。审计记录登录成功/失败、内容创建/编辑/审核/发布/下架、账号操作及越权拒绝；包括操作者、时间、动作、目标、结果和 requestId，追加写入并限制读取。安全事件和审计记录的留存/删除周期需校方确认；测试保留期应可配置。

提供 liveness/readiness 探针、关键服务和数据库的健康检查；至少定义服务不可用、5xx 异常升高、数据库连接失败、磁盘或备份失败四类告警及负责人。七天可通过演示告警模拟证明触发与通知链路；未接入实际通知时标记未完成，不能声称生产告警可用。生产日志权限、保留和告警阈值需校方确认。

## 4. 构建、部署和回滚

1. 固定依赖版本，仓库包含锁文件、Dockerfile 和 Compose。容器非 root 运行、使用非特权端口、数据库不暴露公网；构建上下文排除密钥和无关文件。
2. CI 在 PR 执行安装、格式/静态检查、类型检查、必要单元/集成测试及应用构建；基于临时测试数据库跑迁移。微信开发者工具手测不能由一般构建记录冒充。
3. 发布文档写构建版本、部署目标、配置注入、迁移顺序、健康检查、验证、失败处理和审批负责人。备份先于高风险变更；迁移优先向后兼容，破坏性变更先制定数据恢复与兼容计划。
4. 在测试环境演示一次回滚：记录旧版本、升级、发现问题、恢复旧镜像/配置及健康验证；若数据库无法安全降级，不应只回退代码，需明确前向修复或按演练方案恢复。任何恢复需确认目标环境和数据丢失范围。

## 5. 备份与恢复演练

测试环境生成合成记录，执行逻辑备份，在**独立的临时测试数据库**恢复，检查表结构、记录数量、关键内容与状态；记录备份时间、耗时、恢复时间、操作者、目标、结果及证据。不要覆盖生产数据库。备份加密、异地/隔离存储、访问权限、自动备份、保留期和真实 RPO/RTO 要以学校资源与演练结果确定；未实现不能声称已满足企业恢复目标。

## 6. 上线前必须另行通过

学校确认主体、账号与管理员；域名、HTTPS、平台及相关备案/审核；业务文案/素材/版权与学生肖像授权；隐私政策与数据处理流程；测试/生产资源隔离和最小权限；密钥交接及轮换；审计与告警；备份恢复达目标；容量、兼容、安全及独立评估；应急联系人、值班响应、发布回滚及校方签字。无任一环节的证据只能标记未完成。
