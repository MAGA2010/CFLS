# 七天排期、验收与负责人操作手册

## 每天的交付

| 天 | A 工程与集成 | B 学校内容 | C 校园与服务 | 负责人验收点 |
| --- | --- | --- | --- | --- |
| 1 | 工程可跑、约定/路由/类型、首页骨架、分支规范 | 栏目映射和内容模型、学校/课程骨架 | 新闻/活动/招生流程及表单字段草案、页面骨架 | 三人从同一仓库启动；任务和依赖明确；素材缺口登记 |
| 2 | 导航、公共组件、服务契约和模拟数据读取 | 学校概况群、课程主要页面可浏览 | 新闻列表/详情、学生会与活动骨架 | 从首页进入 B/C 首批页面；互相确认数据接口 |
| 3 | 首页接入数据、后台演示骨架、CI 初版 | 升学、校园设施、课程详情，补齐内容映射 | 招生流程、联系页、表单校验和模拟提交 | 完整主路径第一次跑通；阻塞和范围调整留痕 |
| 4 | 本地草稿/发布流与重置；联调 | 补 25 项映射中负责项目、空状态和长文适配 | 活动报名模拟、筛选/空状态；接入 A 数据服务 | 新闻从演示后台发布后能在前台显示；所有栏目的入口可达 |
| 5 | 合并全部 PR，公共问题、构建与文档 | 自测并交叉评审 C，修缺陷 | 自测并交叉评审 B，修缺陷 | 合并版本完整演示；列 P0/P1 缺陷及负责人 |
| 6 | 收口集成、构建、兼容和交付 | 修复负责模块与支持集成 | 修复负责模块与支持集成 | 逐条运行验收用例；所有 P0 必须解决或声明未通过 |
| 7 | 从干净环境复现，冻结候选版，整理交付 | 回归与验收证据 | 回归、录屏与验收证据 | 负责人在指定 commit 验收；登记遗留，决定是否接受初稿 |

每天开始 10 分钟同步依赖；结束时各自在 Issue 报告证据。第 4 天结束锁定范围，第 5 天结束前合并主要功能，第 6、7 天主要修复与验证。学校素材晚到不应造成团队瞎填真实事实。

## 负责人实际操作

1. 在 Issues 检查是否认领重复，确认 A/B/C 和互审人；确定开工日及每日检查时间。提供合法可公开的素材或标记缺失，不在公开仓库发布内部名单和联系方式。
2. 第 1 天检查小程序工具链是否可用、是否有 AppID；没有时确认合法的本地测试方式并记录体验版受限。A 的最小工程必须真正打开，不能只截图 H5。
3. 第 3 天亲自操作主路径；第 4 天检查 25 项映射，确认哪些是占位；第 5 天看合并后的版本，确认剩余问题的负责人。
4. 第 7 天请 A 给出最终 commit 和运行说明，在不包含私人依赖的环境执行安装与构建；若条件允许由不同于开发者的人完成。按下表逐条记录“通过/失败/阻塞/不适用 + 证据链接 + 责任人”。

## 系统验收用例

| ID | 操作及期望 | 严重度 |
| --- | --- | --- |
| V01 | 从干净环境按 README 安装、构建，微信开发者工具打开首页，无阻塞错误；记录工具和版本 | P0 |
| V02 | 首页全部可见入口能到达对应内容或“待确认”页，返回和导航正常，没有空白页 | P0 |
| V03 | 用 25 项映射逐条点验；每项有真实可操作的入口或明确占位，记录缺失内容 | P0 |
| V04 | 课程、升学、学校和校园生活页面在 375/390px 宽度下长文可读，无遮挡和横向溢出 | P0 |
| V05 | 新闻列表有至少 3 条虚构示例；任意两条进详情的标题和正文相符；无效 ID 有空状态及返回 | P0 |
| V06 | 模拟咨询空填报错；有效演示数据提交成功；重复点击不重复触发；页面声明不会发送/保存真实信息 | P0 |
| V07 | 断网或无数据时，演示内容和明确空状态可读；不存在隐蔽的真实表单网络请求 | P0 |
| V08 | 仓库没有密钥、真实个人信息和未经授权素材；涉及待确认内容均可识别 | P0 |
| V09 | 演示后台新建草稿不出现在前台，发布后可见；重置后回到种子数据，明确仅本机演示 | P1 |
| V10 | 关键词搜索或分类、活动模拟报名、校历和空状态符合各模块约定；不做的标明 | P1 |
| V11 | 交叉评审、测试结果、截图/录屏、已知问题、版本号和启动说明齐全 | P0 |
| V12 | 主要按钮、表单标签和错误说明可读；测试无图、长标题、空列表及重复点击 | P0 |

P0 为验收门槛：全部通过才能说初稿验收通过；受工具条件阻塞的须如实标注，不能算通过。P1 未完成需登记，不阻止负责人接受初稿。功能可操作但出现崩溃、数据错配或错误宣称真实提交属于 P0 缺陷。验收记录至少写环境、执行人、时间、commit、步骤、实际结果及证据。

## 交付清单

- [ ] 默认分支含已合并的代码、锁文件和可追溯提交；最终 commit 已记录。
- [ ] README 包含版本要求、安装/构建/导入/测试命令、环境限制和故障排除；不依赖个人电脑私有路径。
- [ ] `docs/` 有 25 项栏目映射表、接口/数据说明、测试记录、问题与下一阶段清单。
- [ ] 每人 PR 有职责范围、验证命令、实际结果、截图/录屏、已知问题和评审记录。
- [ ] 有 2—3 分钟完整演示视频或可访问录屏链接、操作说明；视频不代替实际运行。
- [ ] 后续列明校方确认、审核、真实数据处理、服务端与权限、备案/平台审核、备份恢复和运营移交等工作。
