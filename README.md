# 成都外国语学校国际部小程序 七天协作任务

这是面向项目负责人、三位开发者及其 AI 助手的执行入口。目标是在 7 个工作日内交付**可在微信开发者工具运行、可供校方内部演示的小程序初稿**。本仓库公开：所有学校名称、数据、素材、联系方式及功能说明均须校方确认后才能对外发布；示例明确标记，禁止上传真实个人信息、密钥和未授权素材。

## 如何领取

1. 打开本仓库 Issues，选择尚未认领的 A、B 或 C 任务；先检查是否已有负责人，将自己 assign 给 Issue；无法 assign 时留言“认领 A/B/C + GitHub 用户名”，由负责人确认，避免重复领取。
2. 先完整阅读 [共同约定](docs/共同约定.md)、[七天排期和验收](docs/七天排期和验收.md) 和自己对应的 [A](tasks/A-工程与集成.md)、[B](tasks/B-学校与课程.md)、[C](tasks/C-校园资讯与服务.md)。
3. 在 Issue 留下预计工作时段和首次可交付时间；创建功能分支和 Draft PR，尽早提交可以运行的代码。每日更新进度、阻塞和需要的决策。
4. 请 AI 先阅读上述文件和最新代码，再实施本角色任务；不得自行扩大范围、伪造测试结果或把模拟功能宣称为真实服务。

## 交付目标

- 覆盖学校、课程、升学、招生、校园生活、新闻与学生会等主要栏目；原需求的 25 项均有对应入口或明确的待确认占位，非全部做到正式业务深度。
- 贯通“首页 → 内容 → 新闻 → 招生咨询模拟提交”及校园活动报名模拟流程；可演示内容编辑到发布的本地模拟流程。
- 输出可重复运行的源码、清晰的环境说明、测试证据、演示录像、缺陷及后续上线计划。
- 阶段成果不等于上线：生产账号与审核、数据保护、内容审核、正式后台和发布等需要后续完成。

## 人员分工

| 角色 | 责任 | 入口 |
| --- | --- | --- |
| A | 工程、设计规范、导航、数据契约、首页、内容管理演示、CI 和集成交付 | [A 任务书](tasks/A-工程与集成.md) |
| B | 学校概况、课程、升学、校园设施与内容数据 | [B 任务书](tasks/B-学校与课程.md) |
| C | 学生会、社团与活动、新闻、招生、模拟表单与联系 | [C 任务书](tasks/C-校园资讯与服务.md) |
| 项目负责人 | 分配角色、校方素材与审批、范围决策、复核和最终验收 | [验收清单](docs/七天排期和验收.md) |

若 A 集成负担过重，由 B 或 C 在第 5 天承接经过 A 指派的缺陷；不要未经协调重写公共框架。负责角色是模块最终交付责任人，不排斥团队互助。

## 注意

任务文档是开发建议，正式学校名称、栏目、数据和业务规则须校方确认。学校现有材料分别描述官网和微信小程序；本次先做小程序，Web 官网站点、正式生产服务不在本轮交付承诺内。需要变更时先记录影响，由负责人决定。
