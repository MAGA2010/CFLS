# A 任务书 工程、公共体验与集成

## 你的结果

你是工程与集成负责人：确保 B、C 可以并行工作，并在第七天把他们的成果合为一个可复现的小程序。你还负责首页、公共交互、本地内容管理演示、自动检查与交付。先读 [共同约定](../docs/共同约定.md) 和 [验收表](../docs/七天排期和验收.md)；不要替学校决定未经确认的事实。

## 输入和依赖

- GitHub 仓库是空仓库，现有文件是任务文档，没有现成的应用代码。以实际仓库为准，先检查再创建。
- 工具链默认 uni-app + Vue 3 + TypeScript；按共同约定第一天验证微信构建，不可行当天由负责人决策。
- B 提供学校/课程/升学内容和 25 项映射中相应的路径；C 提供新闻/校园/招生模块。A 第一日提供类型、服务与路由，避免大家猜接口。
- 校方素材、正式身份、线上后台、AppID 或隐私政策不一定已具备；缺失时用安全占位，写入风险记录。

## 工作包 A1 工程启动与基础约定

1. 建立应用、锁文件、忽略文件和脚本。至少提供安装、微信目标构建、静态检查、测试命令；脚本取名以项目实际为准，README 写准确命令与版本。
2. 使用微信开发者工具实际导入编译产物并打开两个页面，记录版本与结果；不可用就立刻报告、记录阻塞，不冒充小程序验证通过。
3. 创建目录、组件示例、错误页与空状态；确定设计 token、按钮、卡片、列表、页面容器、标题及可见的演示标记。
4. 建立路由清单和 25 项栏目映射骨架，约定页面负责人、路径、状态（演示/占位/待学校确认）和数据来源；B、C 负责填充各自部分。
5. 为 shared 类型及 service 建立可运行接口：列表、按 id 读取、保存草稿、发布、重置种子数据；定义不存在、空列表及本地存储异常的行为。实际返回结构与约定文档一致。
6. 提供模拟数据读取和版本兼容方式。首次运行可初始化；重置不依赖网络。存储故障时能提示，不得把失败显示为成功。用版本键区分演示数据结构变更，避免升级破坏演示。

**验收：**B 和 C 用文档能安装运行并调用示例 service；同一 id 对应同一详情；无效 id 或空数据不会崩溃；首页和两个示例页面在微信目标打开。

## 工作包 A2 首页及导航

1. 制作首页展示区、学校概况、课程、升学、校园生活、学生会、新闻和招生入口；首屏信息清晰，栏目名称与路由一致。
2. 首页动态新闻取 service 的已发布示例；无新闻时展示空状态。禁止写死与详情数据不一致的内容。
3. 导航、返回和跨模块链接完整；目标页未完成时显示待确认或建设中，并提供返回，不做死链。
4. 适配窄屏、长文本、缺图片和加载失败；图片使用可公开授权或自制资源，未有校徽时用文字占位。

**验收：**首页所有入口实际点击可达；显示数据与列表一致；375/390px 没有遮挡；占位和演示状态醒目。

## 工作包 A3 内容编辑与发布本地演示 P1

1. 明确将编辑入口标识为“仅本机演示，不具备登录、权限或线上发布”，不要设置假登录冒充安全控制。
2. 最少支持输入标题、摘要、分类与正文，保存草稿；草稿不能出现在公开展示列表；发布后前台显示，详情内容一致。
3. 给每篇内容稳定 id，更新不意外覆盖其他项目；标题/正文空值应提示；编辑和发布失败可见。
4. 可重置到初始示例，重置前明确提示会清除本机演示修改；不得影响其他系统或真实数据。
5. 通过共同 service 对接 C 的新闻列表；明确仅本机持久化，不支持多端、账号或真实审核。

**验收：**新建草稿→检查前台不可见→发布→前台列表与详情可见→重置→回到初始数据；开发者工具重启后是否保留按文档说明实际验证；本地存储失败有提示。

## 工作包 A4 集成、质量和交付

1. 尽早开 Draft PR；第 2 天开始合并稳定模块，负责全局配置冲突、依赖冲突与路由注册。
2. 建立最小 CI：至少依赖安装、类型或静态检查、微信目标构建（若 CI 无法运行平台工具，清楚区分编译与开发者工具手测）。修复失败，不凭配置文件宣称通过。
3. 按测试表组织 B/C 在开发者工具验证、交叉评审和修复。列出阻塞、严重缺陷、权限或设备条件缺口。
4. 编写 README 的精确安装、构建、导入、执行与故障排查步骤；记录最终 commit、依赖版本、演示数据机制、未完成项及后续上线需求。
5. 第 7 天选择干净环境执行并保存证据；整理录屏、测试记录和交付链接。不能运行的测试注明原因和影响。

## PR 与个人验收

PR 描述必须包含工程和集成范围、项目启动/构建/测试命令及实际结果、运行环境、路由和 service 契约变化、截图或录屏、已知问题、回退方式。至少由 B 或 C review；检查通过后合并。A 任务完成意味着所有 P0 主路径可运行且证据可追溯；P1 后台或 CI 如受阻未完成要明确列入遗留，不能宣称实现。
